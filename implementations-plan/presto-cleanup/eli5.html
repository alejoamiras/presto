Presto cleanup

Three small, stacked reviews: close the launch-only release loophole, update dependencies only after a seven-day observation window, then make long or tangled code fail lint and clean up the existing offenders without sacrificing readability.

1. Close the launch exception

Every release must prove it can update from a real, older release signed by the same key. The launch history stays intact.

2. Refresh dependencies safely

Update JavaScript, Rust, Actions, and CI tools, but reject anything too new or unverifiable. One checker guards resolved dependencies and Actions.

3. Enforce readable limits

Functions over 80 nonblank lines or complexity 15 must be reorganized into coherent responsibilities. Passing by squeezing code together is a failure.
